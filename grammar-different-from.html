🔀 A is different from B ＝ A is not the same as B

同一件事的三種說法：different from／not the same as／A and B are different。按 ①②③ 看句子怎麼變身。

① different from　和…不一樣 ② not the same as　和…不相同 ③ A and B are different　兩個不一樣

📐 三種說法互換公式（背這張就夠了）
說法公式例句
① 最常用A ＋ be ＋ different from ＋ BEnglish is different from Chinese.
② 換句話說A ＋ be ＋ not the same as ＋ BEnglish is not the same as Chinese.
③ 兩個一起當主詞A and B ＋ are differentEnglish and Chinese are different.
🌟 三條黃金規則
1. different 配 from（不是 with／of／than）；the same 配 as（不是 with／like）。
2. ② 的否定字 not 一定放在 be 動詞後面，而且 same 前面一定要 the。
3. 改成 ③ 時，主詞變成「A and B」兩個人事物 → be 動詞要用複數 are／were，而且 different 後面不再接 from。
  1. 比較對象要對等：My bike is different from yours.（✗ from you）；The weather in Taipei is different from that in Tokyo.（✗ from Tokyo）。
  2. 時態跟著 be 動詞走：is／are → was／were → will be。Today's test was different from last week's.
  3. 不只 be 動詞：look／sound／taste／smell／feel ＋ different from 也很常考 → Tea tastes different from coffee.
  4. 名詞與動詞：the difference between A and B（差別用 between…and）／A differs from B（正式用法）。

⚠️ 最常錯的七點

  1. different with / different of my brother → different from my brother.
  2. the same with mine ／ the same like mine → the same as mine.
  3. It is not same as mine. → It is not the same as mine.（same 前面一定有 the）
  4. My bag is different from you. → different from yours（＝your bag，要拿包包比包包）。
  5. A and B are different from. → A and B are different.（③ 的句尾不再放 from）
  6. English and Chinese is different. → English and Chinese are different.（兩個東西用 are）
  7. the difference from A and B → the difference between A and B.
